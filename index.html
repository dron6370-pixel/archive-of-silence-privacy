Архив тишины

Политика конфиденциальности

Последнее обновление: 28 октября 2026 года

Эта политика описывает, как приложение «Архив тишины» (пакет ru.lad.archiveofsilence) обрабатывает данные. Разработчик приложения: oas.

Какие данные обрабатывает приложение

Приложение не запрашивает личные или конфиденциальные данные, не создает учетные записи и не передает данные разработчику или другим организациям через интернет. В текущей версии не используются реклама, рекламные SDK и аналитические SDK; разрешение Android на доступ в интернет для приложения отключено.

Чтобы можно было продолжить историю позже, приложение сохраняет только локально на устройстве технический прогресс чтения: текущую сцену, состояние перехода между текстом и выбором, а также внутренние счетчики сюжетных решений. Эти сведения не содержат имени, адреса электронной почты или введенного пользователем текста.

Где хранятся сохранения и как их удалить

Сохранение находится в закрытой области данных приложения на устройстве и не отправляется на сервер. В приложении нет собственного облачного сохранения. Прогресс можно удалить, очистив данные приложения в настройках Android или удалив приложение. Системное резервное копирование Android, если оно включено на устройстве, регулируется настройками Android и учетной записью пользователя.

Передача данных и безопасность

Приложение не передает сохранение и сведения о действиях в истории разработчику или третьим лицам. Поскольку приложение работает без сетевого доступа, данные сохранения остаются в локальном хранилище приложения, защищенном средствами Android.

Посещение этой страницы

Эта политика размещается как статическая страница на GitHub Pages. При открытии страницы GitHub может обрабатывать технические сведения о запросе, включая IP-адрес, для работы и защиты своего сервиса. Эти журналы ведет GitHub; разработчик приложения не получает их через приложение. Подробнее — в описании GitHub Pages и политике конфиденциальности GitHub.

Изменения политики

Если в приложении появятся сетевые функции, реклама, аналитика или иная обработка данных, эта политика и сведения о безопасности данных в Google Play будут обновлены до выпуска соответствующей версии.
