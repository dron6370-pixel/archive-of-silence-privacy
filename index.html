Архив тишины

Политика конфиденциальности

Последнее обновление: 26 ноября 2026 года

Эта политика описывает, как приложение «Архив тишины» (пакет ru.lad.archiveofsilence) обрабатывает данные. Разработчик приложения: oas.

Какие данные обрабатывает приложение

Приложение не создает учетные записи и не запрашивает имя, электронную почту, контакты, местоположение, фото, видео или аудиозаписи. В приложении используется SDK Яндекс Рекламы для показа баннеров и полноэкранных объявлений. При первом запуске версии с рекламой пользователь может выбрать обычную рекламу или разрешить персонализацию. Выбор сохраняется на устройстве и может быть изменён в разделе «Об игре». Реклама показывается при любом выборе.

Чтобы можно было продолжить историю позже, приложение сохраняет только локально на устройстве технический прогресс чтения: текущую сцену, состояние перехода между текстом и выбором, а также внутренние счетчики сюжетных решений. Эти сведения не содержат имени, адреса электронной почты или введенного пользователем текста.

Где хранятся сохранения и как их удалить

Сохранение находится в закрытой области данных приложения на устройстве и не отправляется на сервер. В приложении нет собственного облачного сохранения. Прогресс можно удалить, очистив данные приложения в настройках Android или удалив приложение. Для приложения системное резервное копирование отключено.

Передача данных и безопасность

Сохранение и сюжетные выборы не передаются разработчику или рекламному SDK. Рекламные данные передаются напрямую SDK Яндекса и шифруются при передаче по HTTPS/TLS. Яндекс сообщает, что при стандартных настройках SDK не собирает точное или приблизительное местоположение; рекламный идентификатор может использоваться для персонализации объявлений при наличии соответствующего разрешения Android и выбора пользователя. Подробнее: Безопасность данных в Yandex Mobile Ads SDK.

Посещение этой страницы

Эта политика размещается как статическая страница на GitHub Pages. При открытии страницы GitHub может обрабатывать технические сведения о запросе, включая IP-адрес, для работы и защиты своего сервиса. Эти журналы ведет GitHub; разработчик приложения не получает их через приложение. Подробнее — в описании GitHub Pages и политике конфиденциальности GitHub.

Настройки рекламы

Выбор о персонализации рекламы можно изменить в разделе «Об игре» приложения. Этот выбор не отключает объявления. Сведения о рекламе и обработке данных доступны в разделах «Реклама» и «Безопасность данных» Google Play.
