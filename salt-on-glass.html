Политика конфиденциальности

Последнее обновление: 23 ноября 2026 года

Эта политика описывает, как приложение «Соль на стекле» (Android package ID ru.lad.saltonglass) обрабатывает данные. Разработчик: oas. По вопросам конфиденциальности можно написать на адрес, указанный в конце страницы.

Какие данные обрабатывает приложение

Приложение не создает учетные записи и не запрашивает имя, адрес электронной почты, телефон, контакты, фотографии, видео, аудиозаписи или местоположение. В нём нет собственного сервера и аналитики.

Для показа баннерной и межстраничной рекламы используется Yandex Mobile Ads SDK. В зависимости от настроек Android и выбора пользователя SDK может получать рекламный идентификатор или другие идентификаторы устройства и передавать их Яндексу для показа и оценки объявлений. Если пользователь выбирает персонализацию, идентификатор может использоваться для подбора рекламы. Если пользователь выбирает обычную рекламу, персонализация отключается, но объявления продолжают показываться. Приложение не запрашивает разрешения на точное или приблизительное местоположение. В стандартной конфигурации SDK Яндекса сведения о местоположении не собираются.

При первом запуске приложение показывает отдельный выбор между персонализированной и обычной рекламой. Его можно изменить в разделе «Об игре». Этот выбор хранится на устройстве.

Сохранения и срок хранения

Чтобы продолжить историю позже, приложение сохраняет на устройстве текущую сцену, состояние чтения и выборы по сюжету. Эти сведения не содержат введённых пользователем персональных данных. Сохранения и выбор о персонализации рекламы остаются в закрытой области приложения: разработчик и SDK Яндекса их не получают.

В приложении нет аккаунтов и облачного сохранения. Локальные данные можно удалить, очистив хранилище приложения в настройках Android или удалив приложение.

Передача данных и безопасность

Рекламные запросы обрабатываются сторонним SDK Яндекса. По сведениям Яндекса, перечисленные для Mobile Ads SDK данные шифруются при передаче по HTTPS/TLS; набор данных зависит от настроек SDK и устройства. Яндекс описывает типы и цели обработки в разделе «Безопасность данных в Google Play». Сохранения и сюжетные выборы в рекламный SDK не передаются.

Посещение этой страницы

Эта политика размещается как статическая страница на GitHub Pages. При открытии страницы GitHub может обрабатывать технические сведения о запросе, включая IP-адрес, для работы и защиты своего сервиса. Эти журналы ведёт GitHub; приложение и разработчик не получают их через приложение. Подробнее — в описании GitHub Pages и политике конфиденциальности GitHub.

Изменения политики

Если способы обработки данных изменятся, эта страница будет обновлена. Сведения в политике, в приложении и в разделе «Безопасность данных» Google Play должны соответствовать друг другу.
